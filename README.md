# 2D 侧视沙盒生存游戏（泰拉瑞亚风格）

纯 HTML5 Canvas + 原生 JavaScript 实现，**零第三方依赖**。双击 `index.html` 即可在浏览器中运行，无需安装、无需联网、无需构建。

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 入口页面，内含 Canvas 与操作提示，加载 `game.js` |
| `game.js` | 全部游戏逻辑（地形/矿脉/合成/昼夜/僵尸/战斗/渲染），可被 Node `require` 用于无头测试 |
| `test-headless.js` | 无头自动化测试，真实步进 600 秒并对各机制做断言 |
| `README.md` | 本文档 |

## 运行方式

### 游玩
直接双击 `index.html`（或用浏览器打开）。推荐桌面版 Chrome/Edge/Firefox。

### 验证
在当前目录执行（仅需 Node.js，无需安装任何依赖）：

```bash
node --check game.js        # 语法检查
node test-headless.js       # 无头测试（600 秒模拟 + 全断言）
```

测试会真实调用 `Game.update` 步进 **36000 步（=600 秒）**，覆盖完整昼夜循环、夜晚僵尸生成、天亮清场与天数递增，并对出生安全、跳跃缓冲、移动碰撞、挖掘放置、四档工具等级、工作台距离、满包合成、四档剑伤害与击杀金币、攻击冷却、接触伤害与无敌帧做实际断言；另用轻量 Canvas stub 实际渲染昼/夜/地下/背包/帮助面板。报告打印真实 `PASS/FAIL` 与模拟秒数，不伪造统计。

## 操作

| 按键 | 功能 |
|------|------|
| `A` / `D` | 向左 / 向右移动 |
| `W` 或 `空格` | 跳跃（短按会缓冲到下一逻辑帧，落地即跳） |
| 鼠标左键 | 选中镐→挖掘 · 选中方块→放置 · 选中剑→攻击 |
| 滚轮 / `1`-`0` | 切换 10 格快捷栏 |
| `E` 或 `Tab` | 打开/关闭背包合成面板（点击格子交换物品、点击配方合成） |
| `H` | 帮助面板 |

## 游戏机制

### 世界生成
- 种子化随机（mulberry32 PRNG）+ 一维值噪声生成起伏地表。
- 二维值噪声在石头区掏出洞穴；随机游走生成**煤（浅）/铁（中）/金（深）**分层矿脉。
- 地表随机生长树木（树干 + 树冠）。
- 出生和重生在现有地形中搜索可站立空位，不修改地形或删除玩家建造。

### 挖掘 / 建造
- 必须选中镐子才能挖掘；方块按镐等级分级：木镐（土/石/木/煤）、石镐（+铁）、铁镐（+金）、金镐（最快）。
- 选中可放置方块时左键放置于空气格，扣除背包数量，且不能放置在玩家身上。
- 鼠标十字光标在触及范围外显示红色。

### 合成（12 配方）
- 基础配方（无需工作台）：木板、木棍、工作台、火把。
- 高级配方（需工作台 4 格内）：木/石/铁/金 四档镐与剑。
- 背包面板右列实时显示每个配方的材料、`[需工作台]` 标记与可合成状态；工作台距离与材料不足会给出中文原因。
- **满包时拒绝合成且不扣除材料**，避免丢产物或白扣。
- 点击背包格子可把主背包物品交换到前 10 格快捷栏。

### 昼夜与照明
- 一个周期默认 120 秒（可配置），余弦插值的环境光在 0.15~1.0 之间渐变。
- 天空颜色昼夜渐变，白天画太阳、夜晚画月亮与闪烁星空。
- 地下随深度变暗；火把发出暖色光晕（`lighter` 合成模式）；夜晚玩家自带微弱光。

### 僵尸与战斗
- 夜晚在屏幕外生成僵尸（上限可配置），追踪玩家，遇墙跳跃，接触造成伤害并击退。
- 选中剑左键攻击，前方命中盒；四档剑伤害 2/4/6/9，攻击有冷却。
- 击杀僵尸掉落 1~3 金币；玩家 HP 归零自动重生并给予无敌帧。
- 天亮时所有僵尸自燃消失，天数 +1。

### HUD
- 左上：红心 HP（满/半/空）、金币、第 N 天（昼/夜）、当前手持物品中文名。
- 底部：10 格快捷栏（图标 + 数量 + 槽位号）。

### 物理
- 分轴 AABB 碰撞（玩家与僵尸共用），固定 60 Hz 逻辑步进，浏览器基于 `requestAnimationFrame` 时间戳累加固定步长，避免大 dt 穿透。

## 原创资产说明
- 全部像素美术由代码用 `Canvas` 基本图元（`fillRect`/`arc`/渐变）即时绘制，**不使用任何外部图片、字体或网络请求**。
- 颜色与形状均为原创：方块带顶层色、矿点、像素边线；玩家、僵尸、红心、工具图标均为手绘像素图。
- 噪声、PRNG、碰撞、光照均为自行实现，无任何第三方库。

## 游戏状态
世界和背包保存在当前页面内存中；刷新页面会重新生成世界。本项目不需要账号、云资源或付费模型额度。
